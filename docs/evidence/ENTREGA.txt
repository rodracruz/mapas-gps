Para revisar el resultado:
1. Abrir mapas-gps-revision.html, el visor autónomo incluido en la entrega.
   Contiene fotografía original, datos, CSS, JavaScript y documentación.
   El núcleo no necesita conexión ni claves.
2. Si el navegador bloquea archivos locales por política, descomprimir todo
   el ZIP, ejecutar `python3 -m http.server 4173` en esta carpeta y abrir:
   http://127.0.0.1:4173/mapas-gps-revision.html
   También está la versión de desarrollo: /revision.html

La apertura file:// está bloqueada por la política del Chromium de QA;
se comprobó este mismo HTML por HTTP y después en modo offline sin
solicitudes externas. No se publicó una URL de vista previa pública.
